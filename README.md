# บ้านของเรา

เปิด `index.html` ในเบราว์เซอร์เพื่อเดินสำรวจบ้านสามมิติด้วยมุมมองบุคคลที่หนึ่ง

- คอมพิวเตอร์ใช้ WASD หรือปุ่มลูกศรเพื่อเดิน ลากเมาส์เพื่อมอง และคลิกรูปเพื่อขยาย
- มือถือใช้จอยด้านซ้ายเพื่อเดิน ลากฉากเพื่อมอง และแตะรูปเพื่อขยาย
- เข้าใกล้ประตูแล้วกดเปิด หรือเลือกห้องจากแถบด้านล่าง
- คลิปอยู่บนป้ายด้านขวาของผนังปลายห้องที่สอง จดหมายอยู่บนผนังปลายห้องที่สาม

## เพิ่มและย้ายรูป

1. วางรูปใหม่ในโฟลเดอร์ `photos/` แนะนำให้ปรับด้านยาวของภาพให้อยู่ประมาณ 1,440 พิกเซลเพื่อให้โหลดเร็ว
2. เปิด `photos.js` แล้วเพิ่มรายการในชุดของห้องที่ต้องการ สามชุดเรียงตาม ความสุข → ประสบการณ์ร่วมกัน → อนาคต
3. ใส่พาธชื่อไฟล์ ขนาดภาพจริงเป็นพิกเซล และคำบรรยายที่ต้องการ ตัวอย่างรายการหนึ่งสำหรับภาพขนาด 1200 × 900 พิกเซล

```js
{ "src": "photos/our-new-memory.jpg", "width": 1200, "height": 900, "caption": "วันนั้นที่เราไปด้วยกัน" }
```

คั่นแต่ละรายการด้วยเครื่องหมายจุลภาค ลำดับในแต่ละห้องกำหนดทั้งตำแหน่งบนผนังและลำดับในหน้าดูรูป ห้องหนึ่งรองรับ 20 รูป ตอนนี้มี 10, 10 และ 8 รูปตามลำดับ จึงมีพื้นที่เหลือ 32 รูป

แก้ข้อความในจดหมายได้ที่ `<p id="letter">` ใน `index.html` เปลี่ยนคลิปได้โดยแก้ `window.HOUSE_FILM` ใน `photos.js`

## GitHub Pages

อัปโหลด `index.html`, `photos.js` และโฟลเดอร์ `photos/` ลงในตำแหน่งที่ GitHub Pages ใช้เผยแพร่ ให้คงโครงสร้างไฟล์ไว้ทั้งชุด หากตรงตำแหน่งนั้นมีเว็บเดิมอยู่ ให้แยกชุดนี้ไว้ในโฟลเดอร์ `memory-house/` แล้วเปิดด้วยเส้นทางลงท้าย `/memory-house/`

รูปและคลิปใน GitHub Pages แบบ public จะเปิดได้โดยทุกคนที่เข้าถึงเว็บหรือ repository
